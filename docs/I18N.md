# English / Spanish

- English text is the key: `t('Full name')`. Spanish lives in `src/i18n/es.ts`. Missing keys fall back to English, so a gap never breaks a screen.
- Variables: `t('{n} cards', { n: 5 })`. Bold or links inside a sentence: `rich(t('Open <b>Preview</b>'), { b: (c) => <b>{c}</b> })`. Keep every `{variable}` and `<tag>` in the Spanish.
- `npm run check:i18n` fails if any phrase in the code (including plan, niche and Studio data and the editor's step labels) lacks Spanish, or a translation breaks a tag or invents a variable.
- `npm run check:copy` fails if a design, niche or layout count is typed by hand.
- The choice is stored in `localStorage` as `fc.lang`, can be forced with `?lang=es` (and is then remembered), and otherwise follows the browser language.

## Covered
Landing, sign-up, sign-in, verify and reset, dashboard, quick setup, publish dialog, editor navigation and field labels, plans, Studio, niche names and blurbs, Terms and Privacy.

## Not covered (still English)
Admin portal, the visitor-facing labels on public cards (the templates), design names (kept as product names), and any sentence not passed through `t()`.
Have a Spanish reader review the wording before launch.
